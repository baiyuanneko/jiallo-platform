# jiallo-platform

[English](./README.md)

基于 Spring AI Alibaba、Antd Design 等流行技术开发的统一 AI 平台。目前提供了 Agentic Chat UI 和 RAG 功能。同时适合个人部署和作为 SaaS 部署。

![screenshot](./assets/screenshot-20260618.png)

> 提醒:目前界面仅支持中文(简体)作为界面语言。

## 功能

* 基于全文检索的 RAG
* 高性能且易于横向扩展
* 多用户设计
* 支持用户组的权限设计
* 分享会话
* 为 Agentic 设计的聊天界面
* 默认的安全设置
* 基于 Java 开发
